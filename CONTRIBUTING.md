# Contributing to Orari Polisportiva

Thank you for your interest in contributing! Please follow these guidelines.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/orari-polisportiva.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Push to your fork and submit a Pull Request

## Code Style

### Backend (Java)
- Use 4 spaces for indentation
- Follow Spring Boot conventions
- Add meaningful comments for complex logic
- Use descriptive variable names

### Frontend (Vue.js)
- Use 2 spaces for indentation
- Follow Vue 3 Composition API style
- Use descriptive component names
- Add JSDoc comments for complex functions

## Commit Messages

Format: `<type>: <subject>`

Types:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `style`: Code style changes
- `refactor`: Code refactoring
- `test`: Adding tests
- `chore`: Maintenance tasks

Example: `feat: add email notifications for bookings`

## Pull Request Process

1. Update README.md with any new features
2. Ensure code follows project style guidelines
3. Test your changes locally
4. Update tests if applicable
5. Write a clear PR description
6. Ensure CI passes

## Reporting Bugs

Include:
- Clear title and description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable
- Environment details (OS, Java version, Node version, etc.)

## Feature Requests

Include:
- Clear title and description
- Motivation and use case
- Proposed solution (if any)
- Alternative solutions
